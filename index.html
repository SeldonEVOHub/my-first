002 这是什么 / What this is

打开文件，页面就开始工作。 Open the file, and the page is already working.

my-first is a static landing page for SeldonEVOHub. The files are the product: HTML, CSS, and a little JavaScript. A cloud agent can change them, open a pull request, and leave a page that proves the work.

my-first 是 SeldonEVOHub 的静态着陆页。文件本身就是产品：HTML、CSS，以及少量 JavaScript。云端代理可以修改它们、打开拉取请求，并留下一页能够证明工作的页面。
